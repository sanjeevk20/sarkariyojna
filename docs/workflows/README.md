# Sathi Workflow Guides - Index

Step-by-step citizen guides (English + Marathi) and team system workflows for Maharashtra and central government services. Each page has a citizen guide image, a Marathi version, a Mermaid system diagram with Sathi touchpoints, and a stage table.

> **Status:** **all 23 guides checked on 27 Oct 2026** (3 batches) against news, district/central government pages and secondary sources, with corrections applied; see each page's *Verification* section. Maharashtra state portals were not reachable from the research environment, so final confirmation against current GRs is still needed, and **Marathi text still needs native-speaker review**.

## Quick routers

- **Age:** below 65 and destitute → [Sanjay Gandhi](sanjay-gandhi.md); 65+ → [Shravanbal](shravanbal.md); 70+ health → [Ayushman Vay Vandana](ayushman-card.md)
- **Housing:** village → [PMAY-Gramin](pmay-gramin.md); city / town → [PMAY-Urban 2.0](pmay-urban.md)
- **Farm irrigation grants:** SC / Nav-Bauddha → [Krushi Swavalamban](krushi-swavalamban.md); ST → [Birsa Munda](birsa-munda.md); farm pond for any farmer → [Magel Tyala Shettale](magel-tyala-shettale.md)
- **Business loan:** open category → [Annasaheb Patil](annasaheb-patil.md); SC / Nav-Bauddha → [Mahatma Phule Mahamandal](mahatma-phule-mahamandal.md)
- **Health:** make the [Ayushman card](ayushman-card.md) first, then use it under [MJPJAY](mjpjay.md)

## Adding a new guide

1. Write `<name>_content.py` (copy any existing one).
2. Run `python3 gen_guide.py <name>_content.py` to produce `<out>.html` and `<out>-mr.html`.
3. Render the guides to PNG with [`render.js`](render.js) (needs Playwright + Chromium):
   `node render.js <out>.html <out>.png '#page'` and `node render.js <out>-mr.html <out>-mr.png '#page'`.
4. Render the Mermaid system diagram to an SVG page (e.g. via Mermaid Live or mermaid-cli), then `node render.js <diagram>.html <name>.png svg`.
5. Add a `<name>.md` page (guide images, diagram, stage table, Verification section) and add a row here.

To rebuild every guide after a content change: `for f in *_content.py; do python3 gen_guide.py "$f"; done`, then re-render the PNGs.
